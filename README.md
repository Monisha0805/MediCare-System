# MediCare System

A web-based Medicine Management System with role-based access for Patients, Doctors, Pharmacists, Delivery Agents, Suppliers, and Admins.

## Features

- **Patient Portal** – Browse medicines, place orders, manage payments, track deliveries
- **Doctor Dashboard** – Issue prescriptions with dosage details
- **Pharmacist Zone** – Restock medicines, view inventory & generate reports
- **Delivery Hub** – Update and track order delivery status
- **Supplier Network** – Supply medicines to inventory
- **Admin Dashboard** – Manage users, orders, prescriptions, deliveries, stock & supplies

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend / DB:** MongoDB (`mongodb` npm package)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/medicare-system.git
   cd medicare-system
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Open `index.html` in your browser to run.
